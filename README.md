# FlipSearch - 搜索引擎切换器

一个简洁高效的 Chrome 扩展，让你在不同搜索引擎之间快速切换搜索结果，无需重复输入关键词。

## 功能特点

- **一键切换** - 在搜索结果页快速切换到其他搜索引擎查看相同关键词的结果
- **智能识别** - 自动提取当前页面的搜索关键词，支持主流搜索引擎
- **自定义引擎** - 支持添加、编辑、删除自定义搜索引擎
- **拖拽排序** - 通过拖拽调整搜索引擎的显示顺序
- **灵活配置** - 可选在新标签页或当前页面打开搜索结果

## 支持的搜索引擎

内置支持以下搜索引擎：

- Google
- Bing
- duckDuckGo
- 百度
- Yandex

同时也支持添加任意自定义搜索引擎。

## 安装方式

### 手动安装（开发者模式）

1. 下载本仓库源码
2. 运行构建命令：
   ```bash
   npm install
   npm run build
   ```
3. 打开 Chrome 浏览器，访问 `chrome://extensions/`
4. 开启右上角的「开发者模式」
5. 点击「加载已解压的扩展程序」
6. 选择项目中的 `dist` 文件夹

## 使用说明

### 基本使用

1. 在任意搜索引擎中搜索关键词
2. 点击浏览器工具栏上的扩展图标
3. 选择想要切换到的搜索引擎
4. 自动跳转到目标搜索引擎的搜索结果页
